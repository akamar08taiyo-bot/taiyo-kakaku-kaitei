# 価格改定のご案内（営業所選択機能付き A4 文書）

太陽シルバーサービス株式会社 向け「紙製品価格改定に伴うお早めのご発注のお願い」を、
営業所ごとに切り替えて印刷・PDF 出力できる A4 1ページの文書作成ツールです。

## 公開URL

https://akamar08taiyo-bot.github.io/taiyo-kakaku-kaitei/

営業所にはこの URL を配るだけで使えます。インストール不要、ブラウザだけで動きます。

## できること

- **19営業所の切替** — 営業所を選ぶと所長名・郵便番号・住所・TEL・FAX が一括で入れ替わる
- **担当者情報の入力** — 担当者名・携帯番号を手入力
- **日付の設定** — 文書の日付（「吉日」表記にも切替可）／改定実施日／ご発注期日
- **対象商品の編集** — 1〜6件まで追加・削除
- **案内文の編集** — 本文の全項目を書き換え可能（`**太字**` と `__赤下線付き太字__` に対応）
- **書体の切替** — 16書体
- **PDF ダウンロード / 印刷** — A4 縦1ページ

## 使い方

1. 上記 URL を開く
2. 上部の操作バーで営業所を選ぶ
3. 担当者名・携帯番号・各日付を入力する
4. 必要に応じて「対象商品を編集」「案内文を編集」で内容を調整する
5. 「PDFをダウンロード」または「印刷」

入力内容はブラウザに自動保存されます（次に開いたときも残ります）。
別のパソコンには引き継がれません。パソコンごとに設定してください。

元に戻したいときは「この営業所の編集をリセット」（選択中の営業所の変更のみ）、
または案内文編集パネル内の「案内文を初期値に戻す」を使ってください。

## 構成

| ファイル | 内容 |
|---|---|
| `index.html` | アプリ本体。依存なしの単一HTML（バニラJS）。ビルド不要 |
| `docs/design-handoff.md` | デザイン仕様書（配色・級数・余白・状態管理の確定値） |

## 更新のしかた

`index.html` を1枚直して push するだけです。GitHub Pages が自動で反映します（反映まで1〜2分）。

```bash
git add index.html && git commit -m "更新内容" && git push
```

反映されないときは、ブラウザで Ctrl+F5（強制再読み込み）を試してください。

## 外部依存（CDN 2件）

- Google Fonts — 書体16種
- html2pdf.js@0.10.1 — PDFダウンロード

社内ネットワークが CDN を遮断している場合、書体は OS 標準フォントで代替表示されます。
PDF ボタンは自動的に印刷ダイアログにフォールバックするため、印刷経由で PDF 保存できます。
